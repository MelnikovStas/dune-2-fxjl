# Dune RTS - Стратегия в реальном времени

Игра в стиле Dune 2 на Java с использованием движка FXGL.

## Возможности игры:
- **Строительство зданий**: Казармы, НПЗ (добывает спайс), Аэродромы
- **Сбор ресурсов**: Спайс автоматически добывается со временем + бонус от НПЗ
- **Производство войск**: 
  - Пехота (дешевая, быстрая)
  - Танки (медленные, мощные)
  - Самолеты (быстрые, дальнобойные)
  - Вертолеты (средние характеристики)
- **Управление войсками**: Выбор ЛКМ, перемещение/атака ПКМ
- **Вражеский ИИ**: Строит здания, производит войска, атакует

## Управление:
- **ЛКМ** - Выбрать юнита
- **ПКМ** - Переместить/Атаковать
- **B** - Построить казармы (200 спайса)
- **R** - Построить НПЗ (300 спайса)
- **A** - Построить аэродром (400 спайса)
- **I** - Обучить пехоту (50 спайса)
- **T** - Обучить танк (150 спайса)
- **P** - Обучить самолет (200 спайса)
- **H** - Обучить вертолет (180 спайса)

## Сборка и запуск:

```bash
gradle build
gradle run
```

## Структура проекта:
- `DuneRTSApp.java` - Основной класс игры
- `UnitFactory.java` - Фабрика юнитов
- `BuildingFactory.java` - Фабрика зданий
- `UnitComponent.java` - Компонент юнита (движение, бой)
- `BuildingComponent.java` - Компонент здания
- `BaseComponent.java` - Компонент базы

## Требования:
- Java 17+
- Gradle 8+
